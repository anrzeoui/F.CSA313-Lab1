# Лаборатори №1: UI автомат тест — Playwright

## Лабораторийн зорилго

Энэхүү лабораторийн ажлаар Playwright ашиглан веб интерфейсийн UI автомат тест бичиж, ажиллуулж үзсэн.

Тест хийхдээ SauceDemo веб сайтыг ашигласан бөгөөд TypeScript програмчлалын хэл болон Playwright framework ашигласан.

## Хийсэн ажлууд

Энэ лабораторийн хүрээнд дараах ажлуудыг хийсэн:

- Linux орчинд Node.js болон npm суулгасан.
- Playwright төслийг үүсгэж тохируулсан.
- TypeScript ашиглан UI автомат тест бичсэн.
- SauceDemo веб сайтад амжилттай нэвтрэх тест хийсэн.
- Буруу нууц үгээр нэвтрэхэд алдааны мессеж гарч байгаа эсэхийг шалгасан.
- Нэвтэрсний дараа барааг shopping cart-д нэмэх үйлдлийг автоматжуулсан.
- Playwright-ийн modern locator болох getByRole, getByText, getByPlaceholder ашигласан.
- expect assertion ашиглан тестийн үр дүнг шалгасан.
- Playwright Codegen ашиглан автомат код үүсгэж туршсан.
- Trace Viewer ашиглан тестийн ажиллагааг шалгасан.
- Тестүүдийг Chromium browser дээр ажиллуулж амжилттай гүйцэтгэсэн.

## Тестүүд

### 1. Амжилттай нэвтрэх

Зөв username болон password ашиглан SauceDemo сайтад нэвтэрч, Products хуудас харагдаж байгаа эсэхийг шалгасан.

### 2. Амжилтгүй нэвтрэх

Буруу password ашиглан нэвтрэх оролдлого хийж, алдааны мессеж гарч байгаа эсэхийг шалгасан.

### 3. Барааг сагслах

Амжилттай нэвтэрсний дараа нэг барааг shopping cart-д нэмээд cart-д нэг бараа орсон эсэхийг шалгасан.

## Playwright ба Selenium-ийн харьцуулалт

Playwright болон Selenium нь хоёулаа веб UI автоматжуулалтын зориулалттай нээлттэй эхийн хэрэгслүүд юм.

Selenium нь олон жилийн турш өргөн хэрэглэгдэж байгаа UI автоматжуулалтын хэрэгсэл юм.

Playwright нь элемент бэлэн болох хүртэл автоматаар хүлээдэг auto-wait боломжтой.

Selenium ашиглах үед зарим нөхцөлд explicit wait-ийг гараар бичих шаардлагатай байдаг.

Playwright нь өөрийн browser-уудыг нэг командаар суулгаж тохируулах боломжтой.

Playwright мөн Codegen ашиглан browser дээр хийсэн үйлдлээс тестийн код үүсгэх боломжтой.

Playwright-ийн Trace Viewer нь тестийн ажиллагааг алхам бүрээр шалгаж, алдаа гарсан үед debugging хийхэд тохиромжтой.

Энэ лабораторийн ажлын явцад Playwright-ийн modern locator болон auto-wait боломжуудыг ашиглахад тохиромжтой байсан.

## Дүгнэлт

Энэхүү лабораторийн ажлаар Playwright ашиглан вебийн UI автомат тест бичих үндсэн ойлголтуудыг практик дээр хэрэгжүүлсэн. Мөн амжилттай болон амжилтгүй login, бараа сагслах зэрэг үйлдлүүдийг автоматжуулж, assertion ашиглан үр дүнг шалгасан. Codegen болон Trace Viewer хэрэгслүүдийг туршиж үзсэнээр тест бичих болон debugging хийх боломжуудтай танилцсан.
